# Three public synthetic journeys

These are newly fictional demonstrations, separate from the research's unseen measured cases, facilitator answers and reviewer keys. Synthetic names, decision statements and fixture timestamps are illustrations, not actual consent, authority or approval.

1. **New project — craft studio seats:** follow the [installed-skill journey](../skills/ba-mate/assets/examples/studio-seat.md). Begin with ambiguity, obtain a labelled fictional evaluator answer, preserve/correct a bad AI proposal, review support and record an exact fictional baseline.
2. **Existing specification — courier kiosk:** follow [the imported-specification journey](existing-specification/README.md). Treat imported approval wording as a claim, identify unsupported retention and record blocking questions.
3. **Approved change — craft studio:** follow [the controlled-change journey](approved-change/README.md). Revise 36 to 60 hours, reject old approval reuse, preserve old content and create a newly reviewed fictional baseline.

Run all three helper rehearsals without models/credentials:

```sh
python3 scripts/rehearse.py
```

To keep outputs, choose a new local directory, e.g. `python3 scripts/rehearse.py --output dist/rehearsal`. The script refuses to overwrite an existing directory. These are author-led helper/fixture checks; installed-host behavioural tests are separate.
