# Optional local skills-pilot record

Blank form; consented collection only. This is not an analytics payload. Keep privately and submit only permitted, reviewed fields through the study's actual process.

Run code (random); stream (skills portability/formative); synthetic case/version; package/framework/schema; host/version; provider/model/revision if exposed; available tools; processing location; start/end; breaks; completion/timeout/failure; assistance; prior exposure; clarification answer IDs; attempts/errors; correction effort; usage if exposed; deviation/refinement reference. Unknown fields are missing, not zero. Never include client names, file paths, content hashes, secrets or private artifacts in an ordinary feedback submission.

## Separate reviewer assessment

Original independent scores for the nine dimensions, evidence notes, unsupported commitments, coverage/trace/risk denominators, completion/time and critical findings. Preserve original ratings and later adjudication separately. No automatic scoring is implemented. Rubric totals do not approve artifacts; participant ratings are not objective accuracy or validated usability scores.
