# Research boundary and provenance

This package operationalises the proposed F4-draft.1 method for SME requirements work. It preserves MRQ/SQ1–SQ3 and O1–O6: adaptive elicitation, ethical/transparency checks, integrated prototype, repeatable quality measures, comparative evaluation and evidence-based adoption guidance. The copied framework specification is bundled with installation-local links in the skill; the compact mechanism mapping explains this implementation's differences.

The BA Mate application remains the reference implementation for the current application-based A/manual, B/generic AI, C/framework treatment. This skills implementation provides an additional formative/portability route. Its interface/tooling/model differences are not silently pooled into the original primary comparison. A later controlled skills comparison needs a prospective treatment definition, matched baseline, materials, timing, consent and protocol amendment where required.

Preserved instrument semantics are in the skill's evaluation reference: nine dimensions and weights, QCORE/QRESP/QWEIGHT, observed correctness/support/coverage measures and the five participant feedback items. These are proposed/calibration instruments, not validated psychometric scales; weighted quality is not correctness or an approval gate. Unknown usage is missing, not zero.

Public fictional scenarios, helper tests and author-led rehearsals establish only observed behaviour/checks. They are not participant outcomes, independent practitioner evidence, proof of effectiveness or research novelty. Public issue feedback can explain friction and defects, but has self-selection, host/model and exposure limitations.

No researcher approval reference, contact, DOI, participant count, study completion date or empirical finding is invented. This package does not freeze or approve the existing study. Actual participant collection must use the approved study process and retention/withdrawal rules; this public repository is not a participant artifact store.

Source lineage: F4-draft.1 specification/research contribution, P2-draft.1 protocol, I2-draft.1 measures and current BA Mate reviewed-proposal/change/export behaviour. Package/framework/schema versions are separate. All public examples are newly fictional and distinct from measured E01–E04 cases and their private facilitator/reviewer materials.
