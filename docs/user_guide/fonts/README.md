# Application font for the user guides

The Word guides use **Google Sans Flex**, the global font declared in the BA Mate application's frontend stylesheet. Regular (400) and bold (700) static TrueType instances were generated from the application's bundled Latin WOFF2 font, at width 100 and optical size 18. No reserved font names are declared in the supplied licence.

The fonts are embedded in the DOCX files. A viewer may substitute a font if it ignores embedding. If needed, install the supplied [regular](GoogleSansFlex-Regular.ttf) and [bold](GoogleSansFlex-Bold.ttf) files using your operating system's font installer, then reopen the document. Installation is optional and is not performed by the skill or guide builder.

The application records its bundled upstream font release as v4.007. Upstream project: [Google Sans Flex](https://github.com/googlefonts/googlesans-flex). The guide build uses these local font files and does not fetch fonts from the network.
