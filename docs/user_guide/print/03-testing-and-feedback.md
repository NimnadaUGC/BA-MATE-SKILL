# BA Mate Testing and Feedback

Guide 3 of 3 · Optional public beta testing · v1.0.5 research beta

Use this pack to try a fictional case and report what happened. The forms are separate from ordinary BA work. Complete the parts that apply; you do not need to answer every question.

## 1 Choose a small test

Install and select BA Mate using Guide 1. Choose one task below. Record the actual tool, model, outcome and help you needed. A copied folder or a plausible answer alone does not prove the skill loaded.

| Task | Fictional input or action | What to check |
|---|---|---|
| Missing decision | A studio wants unpaid seats released “quickly”; no deadline is supplied. | Asks for the deadline and starting event; does not invent numbers or answers. |
| Contradictory proposal | Supply a rule retaining paid seats, then a draft that releases every seat. | Finds the contradiction even with a valid citation; blocks affected approval. |
| Changed baseline | Retain a fictional 36 hour baseline, then request 48 hours. | Preserves the old contents and prepares affected drafts for revalidation. |
| Resume and export | Save a draft, resume from its records and export it. | Uses available history, labels draft status and discloses open items or failures. |

Guide 2 supplies the full pottery example. Record unavailable capabilities as unavailable. After a repair, repeat the failed task and affected journey; retain both results.

### Complete the relevant pages

Record the test details and result. Ratings, written comments and reviewer notes are optional. Type into the answer areas in Word, or print and write on the lines. Keep completed copies privately until you have checked what is safe to share.

### Findings against the supplied evidence

Replace each prompt with a finding and evidence or revision references. Use not assessed where needed; a blank is not a pass. Keep longer findings in a local note.

<!-- reviewer-table -->

| Dimension | Reviewer prompt |
|---|---|
| Clarity | Is the meaning understandable and unambiguous? |
| Completeness | What necessary information or scenarios are missing? |
| Consistency | What conflicts within or between artifacts? |
| Testability | Are outcomes and criteria observable? |
| Relevance | Does the content address the agreed scope and need? |
| Transparency | Are assumptions, uncertainty and AI proposals visible? |
| Stakeholder coverage | Whose needs or authority are missing? |
| Traceability | Do revision links support the claimed meaning? |
| Ethical risks | What confidentiality, fairness or other risks arise? |

<!-- field:critical-findings|Unsupported commitments and critical findings|Identify actual revisions and passages; note invented rules, false approval or data loss if observed.|2 -->

For coverage, trace or risk measures, record units, numerators and denominators; unmeasured values stay missing. Preserve original ratings and later adjudication separately. No automatic scoring is implemented. Ratings do not approve artifacts; skills testing remains separate from the application A/B/C study.
