The supplied [BA Mate logo](bamate_logo.png) is preserved unchanged and embedded in the Word cover. Word packages include the local logo and print diagram variants, so building does not depend on the research parent directory.

PNG copies make the diagrams easy to view in Markdown readers. SVG sources retain selectable text, descriptive titles and accessibility descriptions. The guide provides adjacent text and image alternatives; meaning does not depend on colour alone. All diagram content is licensed under the repository's Apache-2.0 licence.

When editing an SVG, regenerate its PNG at the SVG's native dimensions using an SVG renderer and inspect both. Keep the text consistent with the canonical skill; illustrations must not suggest that adopting a proposal approves it, that citations certify meaning or that every task must follow a fixed sequence.
