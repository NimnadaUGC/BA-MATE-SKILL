# BA-MATE-SKILL v1 project plan

Goal: a standalone public-repository-ready implementation of F4-draft.1, preserving the original research aim: adaptive elicitation, ethical/transparency checks and human-in-the-loop validation of SME requirements work. One canonical skill, local records/optional helpers, five host targets (Cursor added in v1.0.5), Markdown/Mermaid outputs and separate synthetic qualification/public feedback.

## Delivery workstreams

| Milestone | Work and acceptance |
|---|---|
| Alignment | Preserve MRQ/SQ1–SQ3/O1–O6, lifecycle, roles, M1–M7 and original instrument semantics. Record app/skill capability differences and empirical claim boundaries. |
| Core | Implement all modes, source/uncertainty rules, bounded proposals, actual human adoption/approval, selected documents and manual fallback; references self-contained after installation. |
| Records | Schema-1 IDs/revisions, provenance, traces, proposals/reviews, authority/approval, baseline snapshots and changes. Atomic helper transactions; failed writes leave existing data intact. |
| Distribution | Build Codex portable plugin, Claude plugin/marketplace, Gemini extension and Antigravity and Cursor direct bundles from one canonical folder. Provide install/removal and natural-language invocation. |
| Qualification | Structural and integrity tests, three synthetic journeys, explicit/implicit/negative activation cases, M1–M7 host challenges, cross-platform CI. Record observed scope/version/outcomes. |
| Release | Build rc.1 and v1 source/distribution archives/checksums. Preserve candidate defects/fixes and remaining host/pilot gaps. Prepare GitHub metadata; no automatic remote publication. |

## Fixed choices

Python 3.10+ standard library optional helpers; authoritative JSON and readable Markdown; project-local `ba-mate-workspace`; progressive one-skill modes; real BA and synthetic practice; Apache-2.0 consistent with the app; project attribution without invented identities/URLs/DOI. AI never approves or invents confirmed business facts. Helpers record assertions and cannot authenticate identity or certify meaning.

## Boundaries

Application A/B/C protocol remains separate. Skills use is formative/portability unless prospectively amended. No telemetry, accounts, MCP, downloads, new provider APIs or native app ZIP interoperability. Cloud permission, project use and research participation remain distinct. Public material is newly fictional; unseen study packets/keys and participant data remain excluded. Markdown/Mermaid source guaranteed; other rendering/conversion depends on checked host capabilities.

## Completion evidence

See VERIFICATION.md and RELEASE_CHECKLIST.md for actually completed checks, remaining host/pilot qualification and public circulation gates. Creating a package is not empirical validation or marketplace publication.
